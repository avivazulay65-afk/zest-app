# Zest

אפליקציית דיאטה ותזונה בעברית: תוכנית אישית לפי הגוף והמטרה, יומן אכילה, ניתוח ארוחות עם AI, מתכונים וסרטונים, התקדמות, וחברים עם צ'אט.

*Zest is a Hebrew diet and nutrition tracker: a personal plan, food diary, AI meal analysis, recipes with videos, progress charts, and friends with chat. This repository only distributes the app (no source code).*

> **חשוב:** האפליקציה היא כלי עזר ואינה תחליף לייעוץ רפואי או תזונתי. הערכים שה-AI מחשב הם הערכה בלבד. אם יש לך מצב רפואי, הריון, או היסטוריה של הפרעת אכילה, התייעץ עם רופא או דיאטן.

## התקנה

### אנדרואיד (אפליקציה מלאה, עם צעדים ותזכורות)

1. פתח את עמוד [Releases](../../releases/latest) מהטלפון והורד את קובץ ה-APK (`Zest-….apk`).
2. פתח את הקובץ. אנדרואיד יבקש לאשר התקנה ממקור לא ידוע: אשר לדפדפן (או למנהל הקבצים) להתקין אפליקציות.
3. פתח את Zest, הירשם או התחבר.
4. אם Google Play Protect מציג ״App scan recommended״, בחר **Scan app** ואז **Install**. זה קורה בכל גרסה חדשה שמותקנת מחוץ לחנות.
5. **צעדים מדויקים:** בהגדרות ← ״ספירת צעדים״ לחץ ״חבר ל-Health Connect״ (ובדוק ש-Samsung Health משתף צעדים ל-Health Connect). כך הספירה כוללת גם את השעון ותואמת ל-Samsung Health.
6. **עדכונים:** האפליקציה בודקת בעצמה אם יצאה גרסה חדשה כאן, ומציעה ״הורד והתקן״ (בהגדרות או במסך הראשי). הנתונים נשמרים.

### אייפון ו-iPad (אפליקציית ווב)

1. פתח ב-**Safari** את: **https://avivazulay65-afk.github.io/zest-app/**
2. לחץ על כפתור השיתוף ואז על **״הוסף למסך הבית״**.
3. פתח את Zest מהמסך הבית.

העדכון בווב אוטומטי. מגבלות הגרסה לאייפון: אין ספירת צעדים אוטומטית (אפשר להזין ידנית) ואין תזכורות שתייה וארוחות אמינות.

## מפתח Gemini אישי (לניתוח ארוחות ולמאמן)

ניתוח ארוחות, תמונות והמאמן האישי משתמשים ב-Gemini של Google. כל משתמש יוצר מפתח משלו, בחינם:

1. היכנס ל-**https://aistudio.google.com/apikey** עם חשבון Google.
2. לחץ **Create API key** (אם תתבקש, בחר ״Create API key in new project״).
3. העתק את המפתח (מתחיל ב-`AIza`).
4. באפליקציה: **הגדרות ← ניתוח AI ← הדבק ← שמור**.

המפתח נשמר רק במכשיר שלך ולא עולה לענן. אל תשתף אותו. אם המכסה החינמית היומית נגמרת, אפשר לנסות שוב מאוחר יותר.

## חשבון, נתונים ופרטיות

- נרשמים עם שם משתמש וסיסמה (בלי אימייל). שם המשתמש הוא גם ה**מזהה** שבו חברים ימצאו אותך.
- הנתונים שלך (פרופיל, יומן, שקילות, מים) מגובים בענן ומשוחזרים בכל מכשיר שתתחבר אליו, באנדרואיד ובאייפון.
- **חברים:** שולחים בקשה לפי מזהה, והחבר מאשר. רק חברים מאושרים רואים אחד את השני: צעדים, אכילה מול יעד, מים ומדליות, ואפשר לשוחח בצ'אט. שינוי משקל מוצג לחברים רק אם תפעיל את זה.
- אפשר למחוק את כל הנתונים מהגדרות האפליקציה.
